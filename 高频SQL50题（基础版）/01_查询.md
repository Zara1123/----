# 1-1查可回收且低脂的产品
初稿
```
SELECT * FROM Products WHERE low_fats == Y AND recyclable == Y
```
改错
1. 题目只要求返回 product_id，用 * 会把所有列都查出来，输出格式不对
2. MySQL 中判断相等用 单个 =，== 会直接报语法错误
3. Y 没加引号，字符串必须用引号包裹，写成 'Y'，否则会被当作列名/关键字报错
改正
```
SELECT project_id 
FROM Products 
WHERE low_fats = 'Y' AND recyclable = 'Y'
```

# 1-2寻找用户推荐人
```
SELECT name
FROM Customer
WHERE referee_id != 2 OR referee_id IS NULL;
```
判断 NULL 必须用专门的语法：IS NULL / IS NOT NULL。
