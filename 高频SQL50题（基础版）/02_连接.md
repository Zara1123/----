多表拼接:JOIN
|写法|规则|
|:---:|:---:|
|INNER JOIN|只保留两边都匹配得上的行|
|LEFT JOIN|左表全保留，右表配不上的填 null|
|RIGHT JOIN|右表全保留，左表配不上的填 null|

FROM 左表 LEFT JOIN 右表 
ON 拼接规则（...对上了就拼接成功）

# 2-1使用唯一标识码替换员工ID
```
SELECT unique_id, name
FROM Employees LEFT JOIN EmployeeUNI
ON Employees.id = EmployeeUNI.id
```

# 2-2产品销售分析
题目要求“获取 Sales 表中所有 sale_id 对应的...”，所以以 Sales 为左表做 LEFT JOIN。*也就是Sales表有几行，结果就有几行*
```
SELECT product_name, year, price
FROM Sales LEFT JOIN Product 
ON Product.product_id = Sales.product_id
```
# 2-3进店却未进行过交易的顾客
找出 A 表中在 B 表没有对应记录的数据，属于经典的不匹配查找问题。
步骤：
1. 先找出没有产生交易的访问（Visits 中有、Transactions 中没有的 visit_id）
2. 再按 customer_id 分组统计次数
方法一：LEFT JOIN + 过滤 NULL
```
SELECT v.customer_id,
       COUNT(*) AS count_no_trans      --COUNT(*) 是聚合函数，必须配合 GROUP BY 理解：数的不是全表行数，而是“分组后每一组内的行数”。
FROM Visits v                          -- ① 拿出所有"光顾记录"（7次光顾）
LEFT JOIN Transactions t               -- ② 每次光顾去交易表里"对一下"，看有没有交易
    ON v.visit_id = t.visit_id
WHERE t.transaction_id IS NULL         -- ③ 只留下"没对上"的（= 没消费的）
GROUP BY v.customer_id                 -- ④ 按顾客分组，数每人有几次
```
最后一步：GROUP BY + COUNT(*)
按 customer_id 分组，数每组的行数：

30 → 1 行 → count_no_trans = 1
96 → 1 行 → count_no_trans = 1
54 → 2 行（visit 7 和 8）→ count_no_trans = 2
