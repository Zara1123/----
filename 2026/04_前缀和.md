# 4-1找到最高海拔
初稿：
```
class Solution:
    def largestAltitude(self, gain: List[int]) -> int:
        altitude = [0]
        ans = 0
        for i in range(len(gain)):
            altitude.append(gain[i])
            altitude[i+1] = altitude[i] + gain[i]
        for i in range(len(gain)+1):
            ans = max(ans,altitude[i])
        return ans
```
优化
```
for i in range(len(gain)):
    altitude.append(altitude[i] + gain[i])  # 直接追加正确的前缀和
```
