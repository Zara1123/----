# 4-1找到最高海拔
初稿：
```
class Solution:
    def largestAltitude(self, gain: List[int]) -> int:
        altitude = [0]
        ans = 0
        for i in range(len(gain)):
            altitude.append(gain[i])
            altitude[i+1] = altitude[i] + gain[i]
        for i in range(len(gain)+1):
            ans = max(ans,altitude[i])
        return ans
```
优化
```
for i in range(len(gain)):
    altitude.append(altitude[i] + gain[i])  # 直接追加正确的前缀和
```

# 4-2寻找数组的中心下标
初稿：
step1）暴力解法
```
for center in range(len(nums)):
    sum_left = sum(nums[:center])      # 中心左边
    sum_right = sum(nums[center+1:])   # 中心右边
    if sum_left == sum_right:
        return center
return -1
```
值得学习处：
1.数组求和用 sum & 切片

step2）手算一遍，找重复劳动

step3）把“重算”换成“增量更新”
```
class Solution:
    def pivotIndex(self, nums: list[int]) -> int:
        sum_left, sum_right = 0, sum(nums)
        for i, x in enumerate(nums):
            sum_right -= x            # 此刻 sum_right = i 右侧之和
            if sum_left == sum_right:
                return i
            sum_left += x             # 把 x 划给左边，准备看下一个 i
        return -1
```
很聪明的做法:
1.设初值时，左边和=0，右边和=数组和；左边和增加，右边和减小，逼近正解
2.既需要数组下标又需要数组元素时，可以用enumerate。如for i, x in enumerate(nums):
3.注意返回值放的地方，是在右和剔除中心元素后
