# 5-1找出两数组的不同
初稿
```
class Solution:

        answer = first = second = []

            if x not in nums2 and x not in first:
                first.append(x)

改错
1. answer = first = second = [] 三个变量指向同一个列表

这是 Python 的经典陷阱。这样写会让 answer，first 和 second 引用同一个列表对象，往 first 里加元素，second，answer 也会跟着变。必须分开创建：second = []，answer = []，first = []

2.range(nums1) —— range 不能接收列表

range() 只能接收整数，传入列表会直接抛出 TypeError。想遍历列表中的元素应该直接写：for y in (nums2):

改正
```
        first = []
        second = []
        for x in nums1:          # 直接遍历列表
            if x not in nums2 and x not in first:
                first.append(x)
        for y in nums2:
            if y not in nums1 and y not in second:

        answer = []              # 记得定义
        answer.append(first)     # 正确调用方法

优化

为什么用 set（哈希表）?
1.哈希函数 hash(x) 算出元素存储位置 → 查找时直接跳到对应格子，平均 O(1)
2.列表查找 x not in nums2 每次都是 O(n) 的线性查找，整体复杂度是 O(n×m)；哈希表查找 = 算位置直接定位 O(1)

```
class Solution:
    def findDifference(self, nums1: list[int], nums2: list[int]) -> list[list[int]]:
        set1, set2 = set(nums1), set(nums2)
        return [list(set1 - set2), list(set2 - set1)]
```

# 5-2独一无二的出现次数
初稿：
思路：先将列表转换为集合，用集合储存数字，过滤掉重复值。再将集合转为列表的键（用字典记录，数字为键，出现次数为值，每个数字及其出现次数为对。）遍历值若发现有相同值则返回false，否则返回true。

# 5-3确定两个字符串是否接近
我的思路：
观察可知，若两个字符串接近需要满足len(word1)==len(word2);word1的值和word2的值*相互包含*（即set1 == set2）;字符的出现次数也需要一样（用sort从大到小排序，列表values1 == values2）
*分开判断*：不满足任何一个直接return False
```
class Solution:
    def closeStrings(self, word1: str, word2: str) -> bool:
        if len(word1) != len(word2):
            return False
        if set(word1) != set(word2):
            return False
        
        #用字典统计字符出现的次数
        count = {}
        for ch1 in word1:
            if ch1 not in count:
                count[ch1] = 1 
            else:
                count[ch1] += 1
        values1 = sorted(count.values())
        values2 = sorted(Counter(word2).values())
        return values1 == values2
```
1. 注意！字典取值方法是.values

# 5-4相等行列对
分析题目：已知行的顺序，求列的顺序。则求转置矩阵的列。若原矩阵的第 i 行 ↔ 转置矩阵的第 j 行（即原矩阵的第 j 列），则count += 1.
其实也可以不显式转置，直接用*下标映射*：
>原矩阵第 i 行的第 k 个元素是 grid[i][k]，第 j 列的第 k 个元素是 grid[k][j]。
具体实现：
方法一：嵌套循环（O(n³)）
```
n = len(grid)
count = 0
for i in range(n):#枚举行R_i
    for j in range(n):#枚举列C_j
    #逐个元素比较：行的第k个 vs 列的第k个
        if all(grid[i][k] == grid[k][j] for k in range(n)):
            count += 1
return count
```
方法二：哈希表优化（O(n²)）✨ 推荐
>把每一行转成元组用哈希表计数，再遍历每一列去查表。注意：一列匹配时要累加该行出现的次数（对应示例 2 中 (2,4,2,2) 出现两次、贡献 2 对）
```
count = Counter(map(tuple,grid))#统计每行出现次数
return sum(count[column] for column in zip(*grid))
```

① map(tuple, grid) —— 把每行列表变成元组
map(函数, 序列) 的意思是：对序列里每个元素应用这个函数。
为什么要转元组？ 
>因为列表是可变的，不能作为字典/Counter 的键（不可哈希），而元组可以。
② Counter(...) —— 统计每行出现次数
```
cnt = Counter(map(tuple, grid))
# cnt = {(3,1,2,2): 1, (1,4,4,5): 1, (2,4,2,2): 2}
```
③zip(*grid) —— 竖着逐列取出
第一步，*grid 解包：把 grid 里的 4 行"拆开"，作为 4 个独立参数传给 zip：
```
zip(*grid)
# 等价于：
zip([3,1,2,2], [1,4,4,5], [2,4,2,2], [2,4,2,2])
#      ↑参数1      ↑参数2      ↑参数3      ↑参数4
```
第二步，zip 的功能：从*每个参数中依次取同一位置*的元素，打包成一组：
```
grid 按行存放：          zip(*grid) 竖着取：
[3, 1, 2, 2]             第1次 → (3, 1, 2, 2)  ← 第 0 列！
[1, 4, 4, 5]             第2次 → (1, 4, 4, 4)  ← 第 1 列
[2, 4, 2, 2]             第3次 → (2, 4, 2, 2)  ← 第 2 列
[2, 4, 2, 2]             第4次 → (2, 5, 2, 2)  ← 第 3 列
所以 zip(*grid) 达到了"转置"的效果：每迭代一次就得到一列，且恰好是元组类型，正好可以直接去 count 里查询。
```
④ count[column] —— 查询 + Counter 的容错特性
对每个列元组 col，去哈希表里查"这个序列作为行出现过几次"：
count[(3,1,2,2)]  # → 1   第0列 恰好等于 第0行 → 贡献 1 对
count[(1,4,4,4)]  # → 0   没有任何行长这样
count[(2,4,2,2)]  # → 2   第2列 等于 第2行和第3行 → 贡献 2 对
count[(2,5,2,2)]  # → 0
⚠️Counter 查询不存在的键返回 0，不会报错（普通 dict 会抛 KeyError）。
⑤ sum(...) —— 汇总
生成器表达式依次产出 1, 0, 2, 0，求和得 3 ✅
